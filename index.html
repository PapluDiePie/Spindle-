Connect YouTube Music

Spindle reads your playlists and likes through Google's YouTube API. Google needs a free OAuth Client ID that belongs to you. It takes about five minutes, once.

  1. Open Google Cloud Console and create a project.
  2. In APIs & Services → Library, enable YouTube Data API v3.
  3. In Google Auth Platform, set up the consent screen (External). Under Audience, add your own Google address as a test user.
  4. In Clients, create a Web application client. Add this page's address as an authorised JavaScript origin:
  5. Copy the Client ID and paste it below.
