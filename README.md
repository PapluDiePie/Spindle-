# Spindle

A record-shop listening booth for YouTube Music. Pull a record off the wall, drop it on the turntable, and watch it spin up.

- Paste any YouTube Music album, playlist or song link to add it to your crate
- Optional Google sign-in turns every playlist into a crate on the wall
- Installable on your phone as a home-screen app

See [SETUP.md](SETUP.md) for Google sign-in and install steps.
